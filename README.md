# 简历项目助手 1.0 Windows 成品包

1. 下载本分支的 **Code → Download ZIP**，把整个 ZIP 解压到一个可写的目录。建议用较短的路径，并为首次启动留出至少 2 GB 可用空间。
2. 打开解压后的文件夹，双击 **Start.cmd**。第一次会自动校验分卷、合并并解压，完成后打开简历项目助手。
3. 以后可继续双击 **Start.cmd**，也可直接打开 **app** 文件夹内的 **简历项目助手.exe**。

本包使用 V13 Windows 桌面程序，包含离线语音模型。还原过程可以离线完成，无需安装 Python。界面依赖 Microsoft Edge WebView2 Runtime。如果启动后没有打开窗口，请确认系统已安装该运行时。

安装包为全新环境。首次使用时，在 **连接设置** 填写自己的模型 API 地址、模型名称和 API Key。保存后可调用所配置的模型，未配置时可体验演示。GitHub Token 按需填写，首次使用语音请允许应用访问麦克风。包内没有个人会话或密钥。

请将 `app.zip.001` 至 `app.zip.007`、`checksums.json` 和两个启动文件保留在同一目录。遇到分卷缺失或校验失败时，重新下载并完整解压即可。
